# 修复待审核状态课程计入报名数量的逻辑问题

**日期：** 2025-08-22  
**类型：** 重要逻辑修复  
**影响范围：** 报名数量计算、课程选择限制、前端显示逻辑  

## 变更概述

修复了前端剩余课程槽位计算逻辑中的关键问题，现在系统正确地将"待审核"状态的课程计入报名数量，确保学员无法在达到总限制后继续选择课程。

## 问题背景

### 用户反馈
```
待审核也算报名的，这个情况应该只可以在报2门了
```

### 问题现象
从用户截图可以看到：
- **已报名课程 (0/3)** 显示"书法行书二年级 二年级" 状态为"待审核"
- **本次选择2门课程**：陈式太极、乒乓球四班
- **总报名1门课程**（来自2025年秋季）

**问题分析：**
- **2024年秋季**：总数限制为3门课程
- **当前状态**：1门待审核 + 2门新选择 = 3门课程
- **应该限制**：不能再选择更多课程
- **实际显示**：仍然允许选择课程

### 问题原因
1. **后端逻辑正确**：`PENDING`（待审核）和`APPROVED`（已通过）状态的课程都被正确计入报名数量
2. **前端计算错误**：在计算`remainingCourseSlots`时，没有正确考虑总限制和学期限制的综合约束
3. **显示不一致**：用户看到可以继续选择课程，但实际已经达到限制

## 解决方案

### 1. 前端逻辑修复

**文件：** `frontend/src/views/Registration.vue`

**修复内容：**
- 修复`updateEnrollmentLimits`函数中的`remainingCourseSlots`计算逻辑
- 正确考虑总限制和学期限制的综合约束
- 确保"待审核"状态的课程被正确计入限制

**修复前代码：**
```typescript
// 如果总报名数量已经达到学期限制，则不能再报名
if (limits.totalEnrollments >= totalLimit) {
  enrollmentLimits.remainingCourseSlots = 0
} else {
  // 否则按学期限制计算
  enrollmentLimits.remainingCourseSlots = Math.max(0, limits.semesterLimit - limits.currentTotal)
}
```

**修复后代码：**
```typescript
// 如果总报名数量已经达到学期限制，则不能再报名
if (limits.totalEnrollments >= totalLimit) {
  enrollmentLimits.remainingCourseSlots = 0
} else {
  // 🔧 修复：考虑总限制和学期限制的综合约束
  // 剩余槽位 = min(总限制剩余, 学期限制剩余)
  const totalRemaining = Math.max(0, totalLimit - limits.totalEnrollments)
  const semesterRemaining = Math.max(0, limits.semesterLimit - limits.currentTotal)
  enrollmentLimits.remainingCourseSlots = Math.min(totalRemaining, semesterRemaining)
}
```

### 2. 逻辑验证

**修复后的逻辑：**
- **总限制检查**：如果总报名数量达到学期限制，剩余槽位为0
- **综合约束**：剩余槽位 = min(总限制剩余, 学期限制剩余)
- **待审核计入**：`PENDING`状态的课程被正确计入报名数量
