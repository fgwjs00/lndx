# 修复总课程数量限制逻辑 - 确保跨学期报名规则正确

**日期：** 2025-08-22  
**类型：** 重要逻辑修复  
**影响范围：** 报名系统、跨学期限制逻辑、前端显示  

## 变更概述

修复了跨学期报名系统中的重要逻辑错误，现在系统正确实现了"一个人总共只能报名2门课程"的总限制，确保2024年秋季特殊政策不会违反总课程数量限制。

## 问题背景

### 发现的逻辑错误
**用户反馈：**
```
发现一个逻辑错误，学员已经在2024年报名2门课程了2025年就应该报不了
```

### 原有问题分析
1. **总限制缺失**：系统没有实现"一个人总共只能报名2门课程"的总限制
2. **跨学期逻辑错误**：允许学员在2024年报名2门课程后，2025年仍可报名2门课程
3. **政策理解偏差**：2024年秋季特殊政策被误解为可以超过总限制

### 正确的逻辑应该是
- **总限制**：一个人总共只能报名2门课程（毕业不包括在内）
- **2024年特殊政策**：如果2024年秋季报名，最多可以报3门课程
- **跨学期限制**：如果2024年已经报名了课程，2025年就不能再报名

## 解决方案

### 1. 后端逻辑修复

**文件：** `backend/src/utils/enrollmentConfig.ts`

**修复内容：**
- 添加总课程数量限制检查
- 在学期限制检查之前先检查总限制
- 更新政策描述，明确总限制规则

**修复前代码：**
```typescript
// 计算总报名数量
const totalEnrollments = Array.from(semesterStats.values()).reduce((sum, stats) => sum + stats.count, 0)

// 生成政策描述
let policyDescription = ''
if (newSemester.includes('2024') && newSemester.includes('秋')) {
  policyDescription = '2024年秋季特殊政策：最多可报名3门课程'
} else if (newSemester.includes('2025')) {
  policyDescription = '2025年标准政策：最多可报名2门课程'
} else {
  policyDescription = '标准政策：最多可报名2门课程'
}
```

**修复后代码：**
```typescript
// 计算总报名数量
const totalEnrollments = Array.from(semesterStats.values()).reduce((sum, stats) => sum + stats.count, 0)

// 🔧 修复：添加总课程数量限制检查
// 根据用户需求：一个人总共只能报2门课程（毕业不包括在内）
const totalLimit = 2
const totalRemaining = Math.max(0, totalLimit - totalEnrollments)

// 检查总课程数量是否超出限制
if (newCourseCount > totalRemaining) {
  return {
    canEnroll: false,
    maxAllowed: totalLimit,
    currentTotal: totalEnrollments,
    semesterLimit: newSemesterLimit,
    message: `总课程数量限制：最多可报名${totalLimit}门课程，当前已报名${totalEnrollments}门，还可报名${totalRemaining}门`,
    semesterBreakdown: Array.from(semesterStats.entries()).map(([sem, stats]) => ({
      semester: sem,
      count: stats.count,
      limit: stats.limit
    })),
    totalEnrollments,
    policyDescription: '总限制：最多可报名2门课程'
  }
}

// 生成政策描述
let policyDescription = ''
if (newSemester.includes('2024') && newSemester.includes('秋')) {
  policyDescription = '2024年秋季特殊政策：最多可报名3门课程（但总课程数量不能超过2门）'
} else if (newSemester.includes('2025')) {
  policyDescription = '2025年标准政策：最多可报名2门课程（但总课程数量不能超过2门）'
} else {
  policyDescription = '标准政策：最多可报名2门课程（但总课程数量不能超过2门）'
}
```
