# 2025-08-22 添加软删除学员管理脚本

## 📋 变更概述
添加一套完整的软删除学员管理脚本，用于安全地查找、备份和永久删除软删除的学员数据。

## ✨ 新增功能

### 1. 查找软删除学员脚本
**文件：** `backend/scripts/find-soft-deleted-students.js`

**功能特点：**
- 查找所有 `isActive = false` 的软删除学员
- 显示详细的学员信息表格
- 统计相关的报名和考勤记录数量
- 按删除时间倒序排列
- 提供清晰的操作指引

**使用方法：**
```bash
cd backend
node scripts/find-soft-deleted-students.js
```

### 2. 数据备份脚本
**文件：** `backend/scripts/backup-soft-deleted-students.js`

**功能特点：**
- 备份所有软删除学员的完整数据
- 包含学员、报名、考勤的所有相关信息
- 生成带时间戳的JSON备份文件
- 保存到 `backend/backups/` 目录
- 提供详细的备份统计信息

**使用方法：**
```bash
node scripts/backup-soft-deleted-students.js
```

### 3. 永久删除学员脚本
**文件：** `backend/scripts/delete-students-permanently.js`

**功能特点：**
- 支持批量删除指定的软删除学员
- 多重安全确认机制
- UUID格式验证
- 数据库事务保证操作原子性
- 详细的删除进度和结果报告

**使用方法：**
```bash
node scripts/delete-students-permanently.js <学员ID1> <学员ID2> ...
```

### 4. 使用说明文档
**文件：** `backend/scripts/README-student-deletion.md`

**内容包含：**
- 完整的使用流程说明
- 安全操作最佳实践
- 详细的示例和输出
- 故障排除指南
- 注意事项和警告

## 🛡️ 安全特性

### 多重确认机制
1. **显示详细信息**：删除前显示所有将被影响的数据
2. **第一次确认**：输入 `yes` 确认删除意图
3. **第二次确认**：输入 `DELETE` 进行最终确认

### 安全限制
- **仅限软删除**：只能删除 `isActive = false` 的学员
- **UUID验证**：严格验证学员ID格式
- **事务保护**：使用数据库事务确保操作原子性
- **错误处理**：完善的错误处理和回滚机制

### 数据保护
- **自动备份**：提供专门的备份脚本
- **完整性检查**：删除前验证数据完整性
- **操作日志**：详细记录每个操作步骤

## 📊 删除影响范围

永久删除学员时会删除以下数据：
- ✅ 学员基本信息记录 (`student`)
- ✅ 所有报名记录 (`enrollment`)
- ✅ 所有考勤记录 (`attendance`)

**保留的数据：**
- ✅ 课程记录（不受影响）
- ✅ 其他学员的数据（不受影响）

## 🔄 使用流程

### 标准操作流程
1. **查找软删除学员**
   ```bash
   node scripts/find-soft-deleted-students.js
   ```

2. **备份数据（推荐）**
   ```bash
   node scripts/backup-soft-deleted-students.js
   ```

3. **永久删除指定学员**
   ```bash
   node scripts/delete-students-permanently.js <学员ID>
   ```

4. **验证删除结果**
   ```bash
   node scripts/find-soft-deleted-students.js
   ```

## 🚨 注意事项

### 使用警告
- ⚠️ **不可逆操作**：永久删除后无法通过系统恢复
- ⚠️ **生产环境**：在生产环境使用时要格外谨慎
- ⚠️ **数据备份**：建议在大批量删除前创建数据库备份
- ⚠️ **权限要求**：需要数据库读写权限

### 最佳实践
- 📋 **操作前备份**：始终在删除前运行备份脚本
- 📋 **分批处理**：大量学员建议分批删除
- 📋 **验证结果**：删除后验证操作结果
- 📋 **保留日志**：保存操作过程的终端输出
