# 修复学生管理中课程年级显示的问题

**日期：** 2025-08-22  
**类型：** 用户体验修复  
**影响范围：** 学生管理页面、课程信息显示、年级信息展示  

## 变更概述

修复了学生管理页面中课程年级信息显示不准确的问题，现在系统能够正确区分分年级和不分年级的课程，为不分年级的课程显示"不分班级"而不是错误的"一年级"。

## 问题背景

### 用户反馈
```
有些课程是不分班级的，现在在学生管理中显示的是一年级，应该显示为不分班级
```

### 问题现象
在学生管理页面的"所报课程"列中：
- **分年级课程**：正确显示为"课程名称 (一年级)"、"课程名称 (二年级)"等
- **不分年级课程**：错误显示为"课程名称 (一年级)"，应该显示为"课程名称 (不分班级)"

### 问题原因
1. **后端数据正确**：课程数据中包含了`requiresGrades`和`level`字段，能够正确区分分年级和不分年级的课程
2. **前端显示逻辑错误**：学生管理页面只显示课程名称，没有根据`requiresGrades`字段来正确显示年级信息
3. **用户体验问题**：用户无法区分哪些课程是分年级的，哪些是不分年级的

## 解决方案

### 1. 前端显示逻辑修复

**文件：** `frontend/src/views/Student.vue`

**修复内容：**
- 添加`getCourseDisplayName`函数来正确处理课程显示名称
- 根据课程的`requiresGrades`字段来决定显示内容
- 为不分年级的课程显示"不分班级"标识

**修复前代码：**
```vue
<span v-for="enrollment in student.enrollments" :key="enrollment.id" 
      class="inline-block bg-blue-50 text-blue-700 px-2 py-1 rounded text-xs mr-1 mb-1">
  {{ enrollment.course?.name || '未知课程' }}
</span>
```

**修复后代码：**
```vue
<span v-for="enrollment in student.enrollments" :key="enrollment.id" 
      class="inline-block bg-blue-50 text-blue-700 px-2 py-1 rounded text-xs mr-1 mb-1">
  {{ getCourseDisplayName(enrollment.course) }}
</span>
```

### 2. 新增课程显示名称处理函数

**函数：** `getCourseDisplayName`

**逻辑说明：**
```typescript
const getCourseDisplayName = (course: any): string => {
  if (!course) return '未知课程'
  
  const courseName = course.name || '未知课程'
  
  // 如果课程不需要年级管理，显示"不分班级"
  if (course.requiresGrades === false) {
    return `${courseName} (不分班级)`
  }
  
  // 如果课程需要年级管理，显示年级信息
  if (course.level) {
    return `${courseName} (${course.level})`
  }
  
  // 如果没有年级信息，显示课程名称
  return courseName
}
```

**显示规则：**
- `requiresGrades: false` → 显示"课程名称 (不分班级)"
- `requiresGrades: true` + `level: "一年级"` → 显示"课程名称 (一年级)"
- `requiresGrades: true` + `level: "二年级"` → 显示"课程名称 (二年级)"
- `requiresGrades: true` + `level: "三年级"` → 显示"课程名称 (三年级)"
