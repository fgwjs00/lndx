# 课程学员名单添加紧急联系人信息

**日期**: 2025-08-22  
**类型**: 功能增强  
**影响范围**: 课程管理、学员导出

## 📋 变更概述

在课程管理页面的学员名单中添加紧急联系人和紧急联系电话信息，同时更新导出功能以包含这些信息。

## 🔧 具体变更

### 前端变更 (frontend/)

#### 1. Course.vue - 学员名单表格更新
- **文件**: `frontend/src/views/Course.vue`
- **变更内容**:
  - 在学员名单表格中添加"紧急联系人"和"紧急联系电话"列
  - 更新表头显示紧急联系人相关信息
  - 在数据映射中添加 `emergencyContact` 和 `emergencyPhone` 字段
  - 对空值显示"未填写"提示

```typescript
// 新增表格列
<th>紧急联系人</th>
<th>紧急联系电话</th>

// 数据映射更新
emergencyContact: app.studentInfo?.emergencyContact || '',
emergencyPhone: app.studentInfo?.emergencyPhone || ''
```

### 后端变更 (backend/)

#### 1. application.ts - API响应数据更新
- **文件**: `backend/src/routes/application.ts`
- **变更内容**:
  - 在学员信息响应中添加紧急联系人字段
  - 确保课程学员名单查询包含完整的紧急联系人信息

```typescript
studentInfo: {
  // ... 其他字段
  emergencyContact: enrollment.student.emergencyContact,
  emergencyPhone: enrollment.student.emergencyPhone
}
```

#### 2. student.ts - 导出功能更新
- **文件**: `backend/src/routes/student.ts`
- **变更内容**:
  - 在CSV导出头部添加"紧急联系人"和"紧急联系电话"列
  - 在数据行中包含紧急联系人信息
  - 对空值显示"未填写"

```typescript
const csvHeaders = [
  '学员编号', '姓名', '性别', '身份证号', '联系电话',
  '紧急联系人', '紧急联系电话',  // 新增
  '学期', '院系', '年级', '报名课程', '课程学期', '报名状态', '报名时间'
]

const row = [
  // ... 其他字段
  student.emergencyContact || '未填写',
  student.emergencyPhone || '未填写',
  // ... 其他字段
]
```

## 🎯 功能影响

### 新增功能
1. **课程学员名单显示**: 管理员可以在课程详情的学员名单中查看每个学员的紧急联系人信息
2. **导出功能增强**: CSV导出文件现在包含紧急联系人和紧急联系电话列

### 用户体验改进
1. **信息完整性**: 提供更完整的学员联系信息，便于紧急情况联系
2. **数据导出**: 导出的学员数据更加全面，包含紧急联系信息
3. **界面友好**: 对未填写的紧急联系信息显示"未填写"提示

## 🔍 技术细节

### 数据流程
1. 前端请求课程学员名单 → ApplicationService.getApplicationList()
2. 后端查询enrollment表关联student表 → 包含emergencyContact和emergencyPhone字段
3. 前端接收数据并在表格中显示紧急联系人信息
4. 导出功能从同样的数据源获取紧急联系人信息

### 兼容性
- ✅ 向后兼容：对于没有紧急联系人信息的老数据显示"未填写"
- ✅ 数据库兼容：使用现有的student表字段，无需数据库迁移
- ✅ API兼容：扩展现有API响应，不影响其他功能
