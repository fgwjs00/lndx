# 修复跨学期报名逻辑 - 明确总限制规则

**日期：** 2025-08-22  
**类型：** 逻辑修复  
**影响范围：** 跨学期报名限制逻辑、前端显示说明  

## 变更概述

修复了跨学期报名逻辑中的理解偏差，现在系统正确实现了"一个人总共只能报名2门课程"的总限制，明确了2024年秋季特殊政策的适用范围。

## 问题背景

### 用户反馈
```
2024年已报名两门25年就不能在报名了呀
```

### 原有问题分析
1. **逻辑理解偏差**：之前错误地认为"2025年已报名2门 → 2024年还可以报名1门"
2. **总限制不明确**：没有清楚说明总课程数量限制的优先级
3. **特殊政策误解**：2024年秋季特殊政策被误解为可以突破总限制

### 正确的逻辑应该是
- **总限制**：一个人总共只能报名2门课程（毕业不包括在内）
- **2024年秋季特殊政策**：最多可报名3门课程（但受总限制约束）
- **2025年标准政策**：最多可报名2门课程（但受总限制约束）
- **跨学期限制**：
  - 2024年已报名2门 → 2025年无法再报名（总限制2门）
  - 2025年已报名2门 → 2024年也无法再报名（总限制2门）
