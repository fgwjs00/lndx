 # 学员删除管理脚本

本目录包含用于管理软删除学员的脚本工具，可以安全地查找、备份和永久删除软删除的学员数据。

## 📋 脚本列表

### 1. 查找学员 (`find-soft-deleted-students.js`)
查找并显示学员信息，支持查看所有学员或仅软删除学员。

### 2. 备份软删除学员数据 (`backup-soft-deleted-students.js`)
在永久删除前备份所有软删除学员的完整数据。

### 3. 永久删除学员 (`delete-students-permanently.js`)
永久删除指定的软删除学员及其所有相关数据。

## 🚀 使用流程

### 步骤 1: 查找学员
```bash
cd backend

# 查找所有学员（包括正常和软删除的）
node scripts/find-soft-deleted-students.js

# 查找所有软删除学员
node scripts/find-soft-deleted-students.js --deleted

# 通过姓名搜索所有学员
node scripts/find-soft-deleted-students.js 张三

# 通过姓名搜索软删除学员
node scripts/find-soft-deleted-students.js 张三 --deleted

# 通过身份证号搜索
node scripts/find-soft-deleted-students.js 110101199001011234

# 通过身份证号搜索软删除学员
node scripts/find-soft-deleted-students.js 110101199001011234 --deleted

# 通过部分信息搜索
node scripts/find-soft-deleted-students.js 张
node scripts/find-soft-deleted-students.js 1101 --deleted
```

### 步骤 2: 备份数据（推荐）
```bash
node scripts/backup-soft-deleted-students.js
```

**功能：**
- 创建完整的JSON备份文件
- 包含学员、报名、考勤的所有数据
- 保存到 `backend/backups/` 目录
- 文件名包含时间戳

### 步骤 3: 永久删除学员
```bash
node scripts/delete-students-permanently.js <学员ID1> <学员ID2> ...
```

**示例：**
```bash
# 删除单个学员
node scripts/delete-students-permanently.js 12345678-1234-5678-9abc-123456789012

# 删除多个学员
node scripts/delete-students-permanently.js 12345678-1234-5678-9abc-123456789012 87654321-4321-8765-cba9-876543210987
```

## ⚠️ 安全措施

### 多重确认机制
1. **显示详细信息**：显示将要删除的学员详细信息
2. **第一次确认**：输入 `yes` 确认删除意图
3. **第二次确认**：输入 `DELETE` 进行最终确认

### 安全限制
- 只能删除 `isActive = false` 的软删除学员
- 使用数据库事务确保操作原子性
- UUID格式验证防止错误输入
- 详细的操作日志记录

### 数据备份
- 自动备份功能，保存完整数据
- JSON格式，便于数据恢复
- 时间戳文件名，避免覆盖

## 📊 删除影响范围

永久删除一个学员将删除以下数据：
- ✅ 学员基本信息记录
- ✅ 所有报名记录 (enrollments)
- ✅ 所有考勤记录 (attendances)

**注意：** 课程记录本身不会被删除，只删除学员与课程的关联记录。

## 🔄 数据恢复

如果需要恢复误删的数据：

1. **从备份恢复**：
   - 使用备份的JSON文件
   - 编写恢复脚本重新插入数据

2. **从数据库备份恢复**：
   - 使用数据库级别的备份
   - 恢复到删除前的状态

## 🛡️ 最佳实践

1. **操作前备份**：始终在删除前运行备份脚本
2. **分批删除**：如果学员较多，建议分批删除
3. **验证结果**：删除后运行查找脚本确认结果
4. **保留日志**：保存操作过程的终端输出
5. **数据库备份**：在大批量删除前创建数据库备份

## 🚨 注意事项

- ⚠️ **不可逆操作**：永久删除后无法通过系统恢复
- ⚠️ **仅限软删除**：只能删除已经软删除的学员
- ⚠️ **关联数据**：会同时删除所有相关的报名和考勤记录
- ⚠️ **权限要求**：需要数据库写权限
- ⚠️ **生产环境**：在生产环境使用时要格外谨慎

## 🔧 故障排除

### 常见错误

1. **"学员ID格式无效"**
   - 确保使用正确的UUID格式
   - 从查找脚本复制准确的ID

2. **"学员ID未找到或不是软删除状态"**
   - 学员可能已经被永久删除
   - 学员可能不是软删除状态（isActive = true）

3. **"数据库连接失败"**
   - 检查数据库连接配置
   - 确保数据库服务正在运行

4. **"权限不足"**
   - 确保数据库用户有删除权限
   - 检查Prisma配置
